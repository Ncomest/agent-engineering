# Plan-and-Execute

**Problem:** complex tasks have dependencies and acceptance criteria.

**Mechanism:** plan milestones, execute stages, verify each and revise when evidence changes.

**Use:** multi-step tasks with meaningful risks. **Avoid:** trivial requests.

**Benefits:** scope clarity, progress visibility and recoverability.

**Risks:** excessive planning, stale plans, false certainty.

**Example:** document migration: inventory → map destinations → migrate batches → compare results.

**Minimum:** objective, 3–7 milestones, acceptance checks, current step and stop conditions.
