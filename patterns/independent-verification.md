# Independent Verification

**Problem:** authors can overlook their own mistakes.

**Mechanism:** validate an artifact using tests, source documents or a separate rubric-based review.

**Use:** migrations and consequential changes. **Avoid:** repeated model agreement without new evidence.

**Contract:** acceptance criteria, evidence access, failure report and owner.

**Risks:** correlated mistakes, invented defects, expensive review loops.

**Example:** check a Vue change against the API contract and actual test results.
